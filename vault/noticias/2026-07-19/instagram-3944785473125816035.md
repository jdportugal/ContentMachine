## Descrição

Comment "CODING" to get this plugin that reduces your Claude Code output by over 50%.

This secret GitHub repo called Ponytail solves one of the biggest problems in vibe coding.

It cuts your code output by over 50%, saving you thousands of tokens every single session.

You install it once, give it a task, and it forces Claude to actually think and research first. 

Instead of writing code immediately, it checks if a solution already exists.

Like in a library, a dependency, or somewhere already in your own codebase. 

All before it writes a single line of new code.

Most people using Claude Code skip this step entirely. 

They just let Claude write whatever comes to mind first, which usually means duplicate functions, unnecessary files, and bloated logic that eats through your usage fast.

Only once Ponytail confirms nothing already exists does it start coding.

And even then, only the least amount of lines required to get the job done.

This keeps your code clean and simple, with barely any tokens wasted on bloated output. 

No more scrolling through 200 lines of code that could have been 40.

For anyone running long Claude Code sessions daily, this is the difference between hitting your limit by noon or making it through the whole day without interruption.

It works quietly in the background too. 

You don't have to change how you prompt Claude, Ponytail just makes sure every response is leaner than it would've been otherwise.
