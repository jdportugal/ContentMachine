## Descrição

Comment "CLI" to get this AI Plugin to connect Claude Code to any app you use.

This free Claude Plugin tool lets you connect your Claude Code to any app or tool you use.

Even the ones that don't have an official MCP or connector.

Completely free.

It's called CLI Anything.

It lets your Claude Code build a CLI for basically any software you use.

Including the local tools already sitting on your computer.

All you do is point it at an app or repo.

Then it reads its code, writes the commands, and installs it for you automatically.

No manual setup, no digging through documentation yourself.

With it, your agent can actually control things like Blender, Premiere Pro, Zoom, and even NotebookLM.

Directly from your terminal.

Plus since they're all CLI, your agent now uses way fewer tokens than a stack of MCPs would.

Think of it like giving Claude a universal remote instead of hunting for a different remote for every device you own.

No more waiting around for someone to build an official connector for the tool you actually need.

If it has a terminal or an API, this can probably talk to it.
