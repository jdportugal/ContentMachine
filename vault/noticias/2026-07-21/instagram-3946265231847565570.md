## Descrição

Comment "CODEX" to get this new plugin to run Claude Code and Codex together. 

OpenAI just dropped an official plugin that lets you use Codex right inside Claude Code. 

It takes about 30 seconds to set up.

This is actually unprecedented. OpenAI built a plugin for a direct competitor's tool, which almost never happens in this industry.

All you have to do is run two commands, and now you've got two of the most powerful AI coding tools working side by side in one terminal.

With it, you can do things like letting Claude plan out the whole project while Codex builds it for you. 

Two different strengths, one workflow.

Or ask Codex to run a full code review before you ship anything. 

It'll question your implementation choices and pressure-test your decisions before they become a bug report.

Or even have the two of them go head to head. Claude implements, Codex reviews. 

Or flip it, Codex implements while Claude supervises.

Think of it like hiring two senior engineers who disagree on purpose, so the final answer survives more scrutiny than either one alone would catch.

You'll need a ChatGPT subscription, including the free tier, or an OpenAI API key to use it. 

Your existing Codex login carries over automatically.
