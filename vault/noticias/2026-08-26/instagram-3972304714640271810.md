## Descrição

Comment "CLAUDE" to get these 5 plugins and skills for your Claude Code Setup.

If you're using Claude Code, you need to install these 5 AI plugins and skills.

First is find-skills.

You just tell it what you're building.

It searches its whole library of 100k skills.

It finds the best ones and installs them for you.

Second is OmniRoute.

It gives your Claude Code almost unlimited usage by connecting to over 200 free AI providers.

The moment your usage limit runs out, it automatically switches you to the next best model.

Giving you up to 1.6 billion free tokens every single month.

Third is Claude Code Setup.

It's an official Anthropic plugin.

It scans your entire codebase and recommends the best hooks, skills, subagents, and MCP servers that fit your project.

And it removes the useless stuff you don't need.

Fourth is Strix.

It attacks your vibe coded app like a real hacker.

It finds and fixes any security vulnerabilities left behind.

And finally, Agent Reach.

It lets you scrape anything off the internet, even gated platforms like LinkedIn, Instagram, X, and Reddit.

Without any API key required.
