## Descrição

⚡ Stop coding without these VS Code extensions!

These 6 extensions can make your workflow faster, cleaner, and much easier:

✅ Prettier keeps your code consistently formatted
✅ ESLint detects problems and improves code quality
✅ GitLens shows who changed each line and why
✅ Error Lens displays errors directly inside your code
✅ Live Server refreshes your browser automatically
✅ Path Intellisense completes file paths instantly

Small tools can save hours of repetitive work. Save this list and install the extensions you are missing! 🔖
