## Descrição

Comment "SKILL" to get Agent Reach and give your AI agent access to the internet for free.

This AI skill lets you scrape platforms like Twitter, Reddit, YouTube, GitHub, and Chinese platforms like XiaoHongShu and Bilibili.

All without paying for a single API key.

It's called Agent Reach.

It's a free open source CLI tool built for Claude Code, Cursor, and other AI agents.

Just run one install command in your terminal.

Your agent gains access to over a dozen platforms instantly.

Think of it like handing your agent a master key instead of asking it to pick every lock one by one.

Some platforms like YouTube, GitHub, and Bilibili work with zero setup right away.

Agent Reach already knows how to route requests to the right tool underneath.

Others like Twitter and Reddit need you to log in once.

You export your browser cookies, since those platforms require an authenticated session before anything can be read.

That one-time setup takes a couple of minutes.

After that, your agent handles everything on its own.

With it, you can pull YouTube transcripts, search Reddit discussions, read GitHub repos, or check what's trending on Twitter.

All through one single tool.

There's also a built-in doctor command that checks which platforms are ready to go.

It tells you which ones still need that login step, so you're never guessing what's missing.

This used to take a full day of hunting down scrapers and debugging auth flows.

Now it's one command and a few minutes of login.
