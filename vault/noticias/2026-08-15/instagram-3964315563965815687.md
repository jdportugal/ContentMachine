## Descrição

Comment "DESIGN" to get these Claude Code plugins to design better UIs. 

If you want better front-end designs with Claude Code, here are five plugins you need to install right now.

First is Taste Skill.

It pulls real design taste from premium references.

Your UI stops looking vibe-coded.

It's already crossed 76,000 stars on GitHub.

Second is the Web Design Guidelines skill.

It audits your code against Vercel's official design rules.

It flags any issues or weak points before you ship anything.

It even catches accessibility problems most developers miss entirely.

Third is a full design system skill.

It hands your AI a complete design system pulled from top quality websites.

Colors, typography, spacing, buttons, all done for you.

No more guessing which shade of blue matches your brand.

Fourth is 21st Dev MCP.

It gives Claude access to over 10,000 professional UI components and templates.

You add them straight into your project with one command.

Think of it like copying and pasting from a library built by real designers.

And fifth is Playwright CLI.

It gives Claude the power to open a browser and screenshot what it just built.

It catches messy output and errors before you even see them.

Together, these five turn Claude Code from a coder into an actual design partner.
